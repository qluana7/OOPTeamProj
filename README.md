# KGU QUIZ — ref.pdf 기반 Java Swing UI 데모

현재 버전은 사용자가 제공한 `ref.pdf`의 화면을 기준으로 제작했습니다. 두 번째 파트(ACADEMIC LIFE)만 객관식 대신 접시를 클릭해 명중시키는 미니게임으로 연결했고, 첫 번째·세 번째 파트와 나머지 결과·오답 복습 흐름은 기존 구성을 유지합니다.

## 실행

Java 17 이상에서 다음 명령으로 실행합니다. 이미지와 글꼴은 JAR에 포함되어 있어 JAR 하나만 복사해 실행할 수 있습니다.

```sh
java -jar CampusQuiz-demo.jar
```

소스 실행(JDK 17 이상): Linux/macOS는 `./run.sh`, Windows는 `run.bat`. IDE에서는 프로젝트 루트에서 `src/CampusQuiz.java`의 `main()`을 실행하세요.

JAR 재생성: `python3 scripts/build_demo.py`.

## 화면 체험

시작 → 파트 선택 → 파트 소개 → (Part 01·03) 답변 선택/해설 또는 (Part 02) 접시 클릭 → 파트 완료 → 다음 파트 → 최종 결과 → 오답 복습.

첫 번째·세 번째 파트는 기존처럼 답변을 고르면 정답/오답 해설로 이동합니다. 두 번째 파트는 이 화면만 레트로 오락실/도트풍으로 구성했습니다. 시작 직후 빈 스테이지에서 준비한 뒤, Swing 타이머가 좌우 양쪽에서 접시를 랜덤하게 생성합니다. 접시는 수평 이동이 빠른 중력 기반 포물선 궤적으로 날아오고, 마우스 에임이 따라오며 클릭 시 총구·트레이서 효과가 표시됩니다. 정답 접시는 10점을 얻고, 오답 접시는 오답으로 기록되며 정답·오답 결과 화면의 버튼을 눌러 다음 문제로 이동합니다. 5문제를 모두 처리하면 완료됩니다. 종료 확인에서 계속 풀기를 누르면 진행 상태가 유지되고, 종료하면 파트 선택 화면으로 돌아갑니다. 복습 목록의 항목을 누르면 상세 화면으로 이동합니다. Tab과 Space로 Swing 버튼을 조작할 수 있습니다.

UI 데모를 위한 임시 상태만 존재합니다. 첫 번째·세 번째 파트의 실제 문항·점수 흐름은 기존 데모를 따르고, 두 번째 파트는 5개 접시 스테이지를 제공합니다. 최종 소요 시간 `04:32` 등 결과 일부는 데모 값이며, 저장 기능은 구현하지 않았습니다. 화면 문구는 디자인을 따라 표시됩니다.

## 크기와 리소스

1000×1080 논리 좌표를 기준으로 전체 화면과 버튼 영역을 같은 비율로 확대·축소합니다. 기본 창은 800×864, 최소 창은 600×648이며 스크롤은 없습니다. 넓은 창에서는 비율을 유지하고 여백을 둡니다.

PDF의 타이틀 바를 포함한 디자인을 재현하기 위해 창 장식은 Swing에서 그립니다. 최소화·최대화·닫기와 타이틀 바 드래그를 지원합니다.

사진, 손글씨, 결과 아이콘을 PDF에서 추출해 로컬 파일로 포함했습니다. 전체 UI를 PNG 한 장으로 붙이지 않고 텍스트·버튼·진행 막대·패널을 직접 구성했습니다. 글꼴은 Noto Sans 계열을 번들링했으며 Java의 글꼴 렌더링 차이로 원본의 모든 글자 윤곽이 동일하지는 않습니다. [리소스 출처와 배치](assets/README.md)

## 검증

Java 17 타깃 컴파일, 14개 화면 시각 검토 및 4개 창 크기에서 총 56회 렌더링을 확인했습니다. 버튼 이벤트로 답안 선택 전 비활성 상태, 정답/오답 해설, 모달의 배경 조작 차단·취소·종료, 접시 5회 명중, 3개 파트 이동, 최종 결과, 복습 이동과 초기화를 검증했습니다.

```sh
javac --release 17 -encoding UTF-8 -cp out -d out checks/UiSmoke.java
java -cp out UiSmoke
```

현재 환경은 X11 디스플레이 연결이 불가능해 실제 운영체제 창의 수동 조작은 확인하지 못했습니다. 자동 검증은 56회 화면 렌더링과 세 파트 이동, 접시 5회 명중을 포함합니다.
